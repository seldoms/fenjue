# 实操篇：如何正确地和 AI 对话

> 两版正文讲道理，这一本只干一件事：**练手**。整套书是围绕 AI Agent 写的，而跟 Agent 相处的全部功夫，一大半就在「对话」里——问题怎么问、活怎么派、偏了怎么纠、长任务怎么管。光看懂没用，手得动起来。

## 这一篇怎么用

- **六节，一节一个台阶**，难度逐渐加码：第 1 节练把问题说全，第 2 节练追问和识破，第 3 节练整件交活和验收，第 4 节练用工具管长任务（计划工具、目的工具），第 5 节练快捷键和快捷命令，第 6 节练让它教你、拉它开会。
- **每节末尾都有实操演练**：一题基础、一题进阶。基础题拿现成的材料就能练；进阶题必须用你手头真实的工作练——拿真活练，才长本事。
- **每题都写了「过关标准」**：做到什么样算过，自己对着判，不用等谁批。判不准的，看 `答案/实操篇参考.md` 里的参考要点。
- **顺序别跳**：前一节的手感是后一节的地基。第 1 节的「说全」没练顺，第 3 节的派活单必然写不齐。
- **练完要留痕**：每次演练的结果，记进你的三行记录（入门版第 10 章）。一个月回头看，记录就是进步的证据。

## 这一篇练的是两样东西

1. **思维能力**：先猜再问、要证据、会验收、能拍板——对话里每个动作，都是判断在干活。
2. **工具使用**：Agent 不是聊天框，它有计划、有目标、有命令。把这些用顺，你才算真的在「驾驭」它，而不是陪它聊天。

最后一句鼓励：演练题做错了，比看懂了强。看懂是它的本事，做过才是你的。
