# 《焚诀 · 入门版》框架

**这一版写给谁**：写给还没摸过门道的人——包括厂里大约四分之一暂时看不懂强化版的同事。看不懂的原因多半不是笨，是这些事没在他身上发生过，脑子里没有那个场景，道理再对也挂不住。入门版的任务，就是先把场景给他补上。
**和强化版的关系**：入门版解决「看不懂、没感觉」；强化版解决「不会判断、不会组织」。入门版是地基，强化版是楼。地基没打的人直接上楼，必然是空中楼阁——这不是态度问题，是顺序问题。
**这一版的写法**：比强化版更展开、更啰嗦一点也认。每个新概念先给生活里的比方，再给工作里的真事，最后才给定义。宁可多讲一个例子，不许跳步。

## 章节

### 第一部分：先认识 AI

- 第 1 章 什么是 AI
- 1.1 一个好比方：没来过你现场的快脑子新同事
- 1.2 它会什么：读、写、记、算、写代码、看图
- 1.3 它不会什么：不知道你现场的事、记不住没写下来的事、会一本正经地编
- 1.4 为什么它会编：先有个底，后面章节细讲
- 第 2 章 AI 发展到什么程度了
- 2.1 三级台阶：聊天 → 帮你干完整的活 → 自己跑流程（agent）
- 2.2 现在最强的能做到什么、最弱的会闹什么笑话（各给真例子）
- 2.3 一个判断：它涨得很快，半年前的经验要打折
- 第 3 章 AI 能干哪些事
- 3.1 写和改：文档、邮件、总结、方案初稿
- 3.2 读和查：长文档提要点、日志里找异常、表格对数
- 3.3 写代码和改代码：从改一个小函数到搭一个小工具
- 3.4 看和听：截图认错、录音转文字、图上标注
- 3.5 干流程：巡检、验证、整理——交给 agent 连着干

### 第二部分：工具全景（写书时以 2026 年 10 月底核实信息为准，单独标注日期）

- 第 4 章 国外的模型和工具
- 4.1 三家：Claude、GPT、Gemini，各是什么脾气
- 4.2 官方渠道怎么买、怎么用；大陆用起来有哪些现实限制（只讲事实）
- 4.3 编程和 agent 工具：Claude Code、Codex、Cursor 一类，各适合什么活
- 第 5 章 国内的模型和工具
- 5.1 豆包、通义、智谱、Kimi、DeepSeek、元宝，各是什么脾气
- 5.2 官方入口在哪、哪些免费、哪些适合量大便宜的活
- 5.3 国产编程工具和 agent 工具现状
- 第 6 章 混着用，才是正常用法
- 6.1 按活选工具：写代码用谁、读长文档用谁、量大便宜用谁
- 6.2 一份「按活选工具」对照表（随书附，半年一更新）
- 6.3 聚合平台是什么、有什么坑：稳定性、数据别乱传、合规
- 6.4 一条底线：客户的数据、生产的东西，不许往来路不明的工具里塞

### 第三部分：常见场景——先把感觉找出来

- 第 7 章 办公场景十例（每例：原来的做法 → 用 AI 的做法 → 省在哪）
- 写周报、整理会议记录、把聊天记录变成纪要、回邮件、做 PPT 大纲、翻译、查资料、做表格、写汇报、准备发言稿
- 第 8 章 咱们业务里的场景十例
- 日志排查、任务卡死先自查、版本验证、写巡检脚本、改页面、做小工具（如自己写个插件）、整理问题清单、写复盘、查老项目记录、给客户出说明
- 第 9 章 把 AI 当搜索引擎用，是最亏的用法
- 9.1 「买个顶级 Claude 当豆包用」为什么让人鄙视
- 9.2 同一个工具，两种用法，天壤之别（对照演示一个真任务）

### 第四部分：上手——第一个月怎么练

- 第 10 章 先把量用够
- 10.1 每天 1 亿 token、坚持一个月：为什么先上量
- 10.2 量要烧在真活上：每天从工作里领一件，不许拿闲聊凑数
- 10.3 每天记三行：今天用它干了什么、哪次它错了、我哪句没说清
- 第 11 章 第一个月的周计划
- 第 1 周：办公场景全过一遍；第 2 周：拿自己岗位的一件重复活练熟；第 3 周：让它帮你查一次真故障；第 4 周：做一件以前做不了的事（写个小工具、写段脚本）
- 第 12 章 练完怎么进强化版
- 12.1 自查五问：能答上来，就毕业
- 12.2 强化版的读法预告

## 备注

- 第二部分的工具信息时效性强：成书时逐条核实、标注日期；书里同时教读者「怎么自己核实工具现状」，授人以渔，避免书一出就过期。
- 入门版每章末尾留一页「本章的活」：当周必须真干的一件事，不干完不算读过这一章。
- **小问题（Austin 定，两版通用）**：每一小节后留一题，每章后可再加一道综合题；答案统一放在全书最后一页，每道答案带一句理由。题分两类：现实问题（给真场景，问怎么办）和思维训练（考思维方式）。不考背诵，只考判断——入门版的题要简单到小孩能试着答，答错也没关系，想过再看答案，印象才深。
- **给 agent 的自查题（Austin 定，两版通用）**：每小节除了给人的题，再给读者的 agent 一题——读完后自查自纠，把报告交给主人评审。这类题没有标准答案（它的答案就是报告本身），题目要简单、具体，只问一件事，答完能直接照着改。
