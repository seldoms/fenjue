# 每周 AI 新闻

这个板块只放最新一期。旧的期数不删，移到 `存量/` 里按日期存档，随时能翻。

更新节奏：每周五 18:00 由 Luna 自动更新——查过去一周的动向，写新的一期，把上一期转进存量；如果新动向影响了书里时效性强的内容（比如入门版的工具全景），同步修订对应章节。

每期的写法固定：三到五条动向，每条三句话——是什么、为什么与读者有关、对应书里哪一章。没有值得记的动向就明说「本周无重大更新」，不硬凑。

## 创刊号（2026-10-29）

本周值得记的一条动向：豆包的工作企业版开始开放接入其他厂商的模型（Kimi、智谱、DeepSeek 等）。这件事的意义不在豆包本身，在于「混搭」从个人的小技巧，变成了厂商摆上台面卖的做法——对应入门版第 6 章《混着用，才是正常用法》：按活选工具，正在成为行业默认，不是谁的偏方。

另一条是关于这本书自己的：从本期起，这个板块每周五一期。AI 的信息更新太快，一本书要想不过期，就得自己先活起来——对应入门版第 2 章那句判断：它涨得很快，你的经验要定期重验。
